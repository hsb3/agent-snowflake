# Command Palette - Final Configuration

The TUI uses **our custom command palette** (not Textual's built-in) with **17 REPL-specific commands** - NO theme switching.

## Configuration

**In `app.py`**:
```python
ENABLE_COMMAND_PALETTE = False  # Disable Textual's built-in (17 themes)
# Use our custom CommandPalette widget instead
```

**Ctrl+P** → Opens our custom `CommandPalette` modal with REPL commands

## Light/Dark Mode Support

### Toggle Methods

**Keyboard**: `Ctrl+D` - Toggle between light and dark
**Command Palette**: "Toggle Light/Dark Mode" (System category)

### Color Schemes

**Dark Mode** (default - Carbon Gray 100):
- Background: `#161616` (gray-100)
- Text: `#f4f4f4` (gray-10)
- Panels: `#262626` (gray-90)
- Status colors: Green, Blue, Yellow, Red (Carbon palette)

**Light Mode** (Carbon White):
- Background: `#ffffff` (white)
- Text: `#161616` (gray-100)
- Panels: `#f4f4f4` (gray-10)
- Status colors: Same (Green, Blue, Yellow, Red)

**Status Colors** (consistent across both modes):
- Success: `#42be65` (Carbon green-40)
- Error: `#da1e28` (Carbon red-60)
- Warning: `#f1c21b` (Carbon yellow-30)
- Info: `#4589ff` (Carbon blue-50)

## Why Not Textual's Built-in Palette?

**Textual's palette includes**:
- 17 theme options (ambiance, ansi, catppuccin, dracula, etc.)
- System commands (screenshot, etc.)
- Not REPL-specific

**Our custom palette includes**:
- Agent/thread operations (core REPL workflow)
- Navigation shortcuts
- Slash command access
- Light/dark mode toggle (just 2 options, not 17 themes)
- Context-aware REPL actions

**Benefit of our palette**:
- No accidental theme switching
- No confusion from unused options
- Commands organized by REPL concepts
- Searchable with fuzzy matching
- Cleaner, focused UX

## What's NOT Interfering

**Your concern**: "Aren't they interfering with our theme?"

**Answer**: NO interference because:
1. ✅ Textual's built-in palette is **disabled** (`ENABLE_COMMAND_PALETTE = False`)
2. ✅ Our custom palette has **NO theme switching** - only light/dark toggle
3. ✅ Our Carbon colors are **locked in** - only light/dark variants exist
4. ✅ The 17 items are **REPL commands**, not themes
5. ✅ CSS is controlled by us, not switchable via palette
