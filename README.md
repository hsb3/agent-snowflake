# Overview

This repo consist of 3 separate development efforts

1. `agent_snowflake`: LangGraph Agents
2. `repl_client`: Textual REPL that interacts with LangGraph Dev Server REST API (LangGraph-API)
3. `repl_client_graph`: Textual REPL that interacts with LangGraph Dev Server REST API + uses LangGraph library to manage the underlying control flow and keep state

---
Currently, 3 above are organized under src/ but plan to refactor to make this more appropriate structure

---

- `repl_client_graph` is an experiment to see if there are any benefits to building with LangGraph for control flow in non-agentic python applicatios.  It largely borrows from `repl_client` for base classes.
- `repl_client` is inspired and informed by many of such similar projects I have seen floating around, including:
  - `langchain-ai\deepagents-cli`

Specifications and other planning documents are stored in docs/dev_docs:
  - `spec-agent`: `agent_snowflake`
  - `spec-repl`: `repl_client`
  - `spec-repl-graph`: `repl_client_graph`


It is the intention that both `repl_client` and `repl_graph` have no dependencies on `agent_snowflake` and would generally work with any server with the same schema as langgraph-api.  However, it should be noted that customized agents with custom config_schema and context_schema values or those with tools with special signatures that are intended to be rendered in frontend, will require modification.

Both REPL instances are early stage and are likely to be extremly buggy.

## ai coding agent plug-ins

I am building this with the assistance of ai coding agents --- primarily claude code but also may use opencode, gemini cli, codex cli, or others.

All these coding agents share common primitives that extend or control their behavior, including:
- "memory" docs | special instructions | agents/subagents
- skills: collection of instructions with executable script examples
- hooks: code execution triggered by coding agent control harness events
- mcp servers
- permissions

For claude code, below are in effect via `.claude/settings.local.json`:
- very broad permissions but restricted access to TODO.md (personal scratch notes)
- docs-langchain mcp server for Langchain AI
- `work-documentation@hsb3-custom-plugins`: control how/when .md docs are created
- `ty@hsb3-custom-plugins`: trigger type checking
